# BrandGuard — Improved Prototype

A responsive, static HTML/CSS/JavaScript demo for brand-governance review.

## Run locally
Open `index.html` in a modern browser.

## Deploy
Upload `index.html` (and optionally this README) to a GitHub repository, then import the repository into Vercel. No build command is needed for this static page.

## Important limitations
- Uses sample keyword/rule-based checks only; no external AI service is called.
- Findings are prompts for human review, not proof that a claim is false.
- Review records are downloaded locally as JSON; they are not stored on a server.
